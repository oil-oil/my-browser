Local Chrome, agent controlled

Your real browser, ready for agents.

My Browser gives AI agents a quiet way to work inside your existing Chrome: current login state, real tabs, task groups, local-only control.

npx skills add oil-oil/my-browser

Install the skill, then let your agent open, inspect, upload, and clean up task tabs without launching a disposable profile.

Cleans up

Task tabs can be grouped, verified, closed, or kept when the workflow needs them.

Built for workflows that cannot live in a throwaway browser.

Some tasks need your real browser context: creator platforms, logged-in dashboards, browser extensions, proxy settings, and long-lived sessions. My Browser wraps that context in a small command surface that agents can use deliberately.

Open pages into task-specific Chrome tab groups instead of scattering work across your tab bar.
Inspect pages with compact snapshots, stable refs, scoped summaries, screenshots, console logs, and network diagnostics.
Interact with forms, upload inputs, checkboxes, selects, scrolling regions, and high-impact actions with confirmation gates.
Keep sensitive browser permission prompts under user control; the agent can guide, but it should not bypass consent.
